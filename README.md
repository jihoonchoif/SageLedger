# SageLedger

SageLedger is a multi-tenant, scalable framework that streamlines accounting operations through automated reconciliation and real-time financial reporting capabilities.

SageLedger is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/SageLedger.git`
2. `cd SageLedger`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
